Accessibility Considerations

Accessibility will be an important part of the Flock Block website. I want the website to be usable by as many people as possible, including users with visual, hearing, motor, or cognitive disabilities. I will use clear headings and semantic HTML elements so that screen readers can better understand the structure of each page. Images will include descriptive alt text when the image provides important information. I will also make sure that text has enough contrast with the background so it is easy to read.

The website will also be designed so users can navigate through links and other interactive elements with a keyboard instead of requiring a mouse. Links will use descriptive text instead of unclear phrases such as "click here." I will avoid relying only on color to communicate important information. The website will use readable font sizes, simple page layouts, and responsive design so content can be viewed on computers, tablets, and mobile devices. As the website develops, I will continue reviewing WCAG accessibility recommendations to improve the usability of Flock Block.
